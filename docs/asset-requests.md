```
写実ではなく、でもかわいすぎない。大人も泣ける静かな絵本の雰囲気。

人の顔や全身は絶対に描かない。文字・看板の文字・ロゴも描かない。
既存のアニメやキャラクターに似せない。
舞台: 日本の小さな町の、なんでもない一日。
```
